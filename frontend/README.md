# AI Healthcare Operations Command Centre — frontend

React + TypeScript, built with Vite (see `CLAUDE.md` in this directory for
why Vite rather than the CRA the root `CLAUDE.md` documents).

## Local development

```
npm install
npm run dev      # dev server with HMR
npm run build    # typecheck + production build
```

Walking skeleton: only a placeholder page exists so far. See `PROGRESS.md`
at the repo root for what's built and what's next.
